# 模型增强工作台 UI 改版设计

## 目标与边界

让 `dsh-provider-plus` 的界面融入 DeepSeek Harness「设置 → 模型」：提供商收起时以单行列表呈现，编辑在当前行内展开；字体、颜色、间距和信息层级统一，减少拥挤感。

本次只修改 `lib/client.js` 的界面结构和样式。保留全部现有功能、字段、校验、请求、持久化、轮询、确认提示和结果含义。`lib/index.js`、插件协议和配置格式不变。入口位置继续是「设置 → 模型增强」、内置模型卡片扩展条和输入框用量入口。

## 视觉基准

以本机 Harness「设置 → 模型」页面为参照：白色页面、单列提供商行、轻边框、约 54px 的行高、约 8px 的行间距，以及当前行内的浅灰编辑区域。使用宿主提供的字体与颜色变量，确保浅色和深色主题都可用；以下色值仅是宿主变量不可用时的浅色回退。

| 层级 | 规格 |
|---|---|
| 页面标题 | 16px、600，主文字 `#20242a` |
| 提供商名称 | 14px、600，主文字 |
| 分区标题与控件文字 | 13px、500–600；控件正文 13px |
| 字段标签 | 12px、500，次级文字 `#68717b` |
| 说明和时间 | 12px、常规，提示文字 `#89919a`；重要错误不使用提示色 |
| 页面与列表 | 白色；边框回退 `#e1e4e8`；不叠加有色卡片背景 |
| 展开编辑区 | 浅灰 `#f6f7f8`；只用一层背景区分编辑态 |
| 强调色 | 沿用 Harness 品牌变量，只用于焦点、链接和选中态 |
| 状态色 | 沿用现有成功、警告、错误变量；状态点含义不改变 |

字体沿用宿主字体栈，不引入新字体。普通按钮至少 30px 高，输入框至少 36px 高；不再将主要操作文字压到 11px。通过大小、位置和留白建立层级，不靠大量色块、阴影和徽章。

## 工作台布局

页面标题下保留一行简短说明。提供商按单列排列，每行只显示名称、必要的现有状态和「编辑」。状态的来源和含义沿用现有 `keyConfigured` 与探测结果，不把“配置了密钥”伪装成“连通成功”。「新建提供商」放在列表末尾，外观参照 Harness 的添加入口。

点击「编辑」仍在该提供商行内展开，继续使用现有 `draft`、`tab`、保存与取消逻辑。展开区只设一层浅灰背景和充足内边距；保留「模型配置／用量测试」两个既有页签。模型配置按“基本信息 → 密钥与请求头 → 模型”排列，保留现有折叠状态；用量测试仍保留模板、HTTP 请求与字段映射、拉取测试和结果展示。所有已有按钮仍可到达，连通性测试放在展开区的提供商操作位置，用量测试按钮与对应页签关联，删除放在展开区末尾并沿用现有确认流程。

字段采用单列为主；同组的短字段在足够宽时可并列。分区间距 24px、字段间距 16–20px、标签与控件间距 7–8px、列表行间距 8px。窄容器下并列字段改为单列，按钮允许换行，不截掉提供商名称或操作。

## 模型与用量的密度控制

模型列表仍可编辑 ID、显示名、上下文窗口、图片开关并移除模型；保留从端点拉取、导入和手动添加。宽屏中使用清晰的表头和行间距；窄屏中每个模型改为分组排列，避免五列输入框被压窄。只改呈现，不改模型数据结构、顺序或保存方式。

用量页保留全部预设和请求字段。预设按原有类别分组，增大点击区域与间距；结果区减少重复边框和三层卡片背景，数值、单位、更新时间明确分级。未配置、查询中、成功、失败各状态沿用现有判断与文案含义。

## 另外两个界面入口

内置模型卡片下的扩展条和输入框用量入口也统一到同一字号、次级文字与按钮风格。保留图片支持数量、连通性探测、当前模型用量及弹出详情的现有交互，不增加新的业务数据或接口。

## 验收

1. 收起时每个提供商只占一条清楚的横行，页面没有常驻的多按钮工具栏或层层叠加的灰色卡片。
2. 展开后字段和分区容易扫读；文字有明确的主次，提示文字较当前更轻但仍可辨认。
3. 在常见设置弹窗宽度及较窄窗口中，名称、输入框、模型操作和保存按钮不会互相覆盖或不可见。
4. 新建、编辑、删除、模型发现与导入、图片开关、密钥与请求头、连通性探测、用量预设与查询、输入框用量展示的行为与改版前一致。
5. 浅色和深色主题都检查视觉层级；现有 smoke 测试通过，并通过实际页面检查收起、展开、创建、模型列表、用量页与窄窗口状态。
